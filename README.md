# bookingCabinet
Задача:
В офисе есть 5 кабинетов. Не используя фреймворки, написать команду, которая проверяет свободен ли кабинет в определенное время и даст возможность его забронировать.
После бронирования кабинета, чтоб была команда — «Отправлять уведомление человеку, который занимает его (на E-mail и номер телефона) с датой, временем и номером кабинета». Если кабинет занят, выводить сообщение кем и до скольки он занят. Использовать СУБД. Желательно использовать PSR-рекомендации.
